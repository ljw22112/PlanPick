# 플랜픽 (PlanPick)

**대화로 고치는 대학생 AI 생활계획표** — 시간표·LMS 과제·개인일정을 모아 이번 주 공부 블록을 자동으로 배치하고, "목요일 저녁은 비워줘" 같은 한국어 한마디로 계획을 다시 짭니다.

데모: https://ljw22112.github.io/PlanPick/

## 무엇이 다른가

| | 시간표 | LMS 과제 수집 | 자동 계획 | 대화형 수정 |
| --- | --- | --- | --- | --- |
| 국내 시간표·캘린더 앱 | O | 일부 | X | X |
| 해외 AI 스케줄러 | X | X | O | 일부 |
| **플랜픽** | O | O (.ics) | O | O |

## ICC 융합 포인트

| 융합 | 기능 | 동작 |
| --- | --- | --- |
| 인공지능 × 헬스케어바이오텍 | **컨디션 맞춤 계획** | 웨어러블(수면·스트레스) 또는 대화("어제 4시간밖에 못 잤어")로 오늘 컨디션을 기록하면, 오늘 공부량을 줄이고 블록을 60분으로 짧게, 휴식을 20분으로 늘려 남은 분량을 뒤로 옮깁니다. 컨디션이 좋으면 15% 늘립니다. |
| 인공지능 × 스마트로봇·모빌리티 | **이동 인지 계획** | 수업이 있는 날 통학 구간을 자동 생성해 책상 공부와 겹치지 않게 하고, 대중교통이면 퀴즈·암기·발표 준비 같은 가벼운 과제를 '이동 중 학습'으로 배치합니다. 자차면 넣지 않습니다. |

데모의 웨어러블 버튼은 모의 데이터입니다. 실제 서비스는 Health Connect(안드로이드)·HealthKit(iOS)와 실시간 대중교통 정보를 연동합니다.

## 기능

첫 방문 때 핀터레스트형 카드로 관심사(학점·알바·운동·컨디션·통학·대외활동·어학·취업 + 대외활동 분야)를 고르면 기능·예시 문장·추천이 맞춤으로 바뀝니다.

| 영역 | 기능 |
| --- | --- |
| 가져오기 | LMS .ics 과제, 시간표 사진(AI), 강의계획서 PDF(주차별 시험·과제), 단톡방·학과 공지 붙여넣기(회의·마감·마감 연기), 알바 근무표 사진(AI), 학사일정(예시), 개인 캘린더 .ics |
| 계획 엔진 | 마감 우선 배치, 과제 단계 쪼개기(단계별 중간 마감), 시험기간 모드(D-7·4·2·1 복습), 운동·어학 '주 N회' 목표, 알바·대외활동 일정 반영, 실제 소요시간 학습 보정, 집중 잘 되는 시간대 우선, 반복 규칙("앞으로 금요일 밤엔 공부 안 해") |
| ICC 융합 | 컨디션(수면·스트레스) 맞춤 공부량, 통학 구간·이동 중 학습, 지하철 지연 반영(시연), 스트레스 지속 시 상담 안내 |
| 실행 | 블록 시트(배치 이유·완료/못 함·쪼개기), 집중 타이머, 블록 10분 전 알림, 지금/다음 위젯, 시작 도우미(대신 써주지 않음), 제출 체크리스트 |
| 대화 | 한국어 대화 수정, 음성 입력, 배치 이유 설명("왜 이 시간이야?"), "만약 ~하면?" 시뮬레이션, 에이전트 모드(미리보기 후 적용 / 바로 적용) |
| 먼저 챙겨주기 | 아침 브리핑(오늘 할 일·공강 활용·마감 위험·번아웃·대외활동 마감), 저녁 회고(완료 체크 → 내일 재계획), 밀린 블록 자동 재배치, 배치 못 한 과제 해결 선택지 |
| 대외활동 | 희망 분야·시간표 겹침·지원서 준비 가능 여부로 공고 점수화, 새 공고 알림, 준비 일정 바로 넣기 |
| 함께 | 팀플 공통 빈 시간(공유 코드, 서버 없음·일정 이름 미포함), 스터디 시험 계획 공유 |
| 리포트 | 주간 시간 분배·달성률·시간대별 실행, 학기 회고(과목별 실제/계획), 대학용 익명 통계 대시보드(`admin.html`, 모의 데이터) |

시연 표시가 붙은 기능(웨어러블, 지하철 지연, 대외활동 공고, 대학 대시보드)은 실제 연동 대신 동작 원리를 보여주는 모의 데이터를 씁니다.

## 두 가지 모드

| 모드 | 동작 |
| --- | --- |
| 기본 모드 | 규칙 기반 한국어 파서(`js/nlu.js`). 요일·시간 표현, 과제 이름, 설정 문장을 인식합니다. 키 없이 바로 체험 가능. |
| AI 모드 | 설정에 Claude API 키를 넣으면 LLM이 **함수 호출(tool use)** 로 요청을 해석합니다(`js/llm.js`). 키는 브라우저 localStorage에만 저장되고 Anthropic API로만 전송됩니다. |

## 설계 원칙: LLM은 시간을 직접 배치하지 않는다

```
사용자 발화 ──▶ LLM / 규칙 파서 ──▶ 상태 변경 연산(add_event, block_time, set_task_goal …)
                                          │
                                          ▼
                              제약 기반 스케줄러(scheduler.js)
                                          │
                                          ▼
                         변경안 미리보기 → 적용 → 되돌리기 가능
```

LLM은 말을 **제약**으로 바꾸고, 실제 배치는 결정적 알고리즘이 합니다. 그래서 일정 겹침이나 마감 누락 같은 환각이 계획에 들어가지 않습니다.

## 구조

```
index.html        화면
styles.css        스타일
js/app.js         UI·상태 관리·미리보기·되돌리기
js/scheduler.js   마감 우선(EDF) 탐욕 배치, 계획 diff
js/state.js       데이터 모델, 데모 데이터, 상태 변경 연산
js/nlu.js         규칙 기반 한국어 파서
js/llm.js         Claude API 함수 호출, 시간표 이미지 인식
js/ics.js         LMS·개인 캘린더 .ics 파서
js/agent.js       브리핑·회고·마감 위험·번아웃·공강·배치 이유·해결 선택지
js/extract.js     단톡방·공지·강의계획서(PDF) 추출
js/opportunities.js 대외활동 추천(가상 공고 피드)
js/onboarding.js  첫 방문 관심사 카드
js/share.js       팀플 공통 빈 시간·스터디 공유 코드
js/report.js      주간 리포트·학기 회고
admin.html        대학용 익명 통계 대시보드(모의)
```

빌드 도구 없이 정적 파일로 동작합니다. 로컬 실행:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
